# 오늘의 한 문장

HTML, CSS, JavaScript로 만든 간단한 명언 생성 웹페이지입니다.
버튼을 클릭하면 새로운 명언이 무작위로 표시되고, 라이트 테마와 다크 테마를 선택할 수 있습니다.

## 실행 방법

1. 이 저장소의 파일을 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. `새로운 명언 보기` 버튼을 클릭해 명언을 변경합니다.

별도의 서버나 라이브러리 설치 없이 실행할 수 있습니다.

## 파일 구조

```text
.
├── index.html  # 웹페이지의 구조와 콘텐츠
├── style.css   # 색상, 레이아웃, 반응형 디자인과 애니메이션
├── script.js   # 명언 변경, 테마, 복사 기능
└── readme.md   # 프로젝트 설명서
```

## 주요 기능

### 랜덤 명언 생성

- JavaScript 배열에 24개의 명언 데이터를 저장했습니다.
- 각 데이터에는 명언 내용, 작가, 카테고리가 포함되어 있습니다.
- `Math.random()`을 사용해 명언을 무작위로 선택합니다.
- 직전에 표시된 명언과 같은 명언이 연속으로 나오지 않도록 중복을 방지합니다.

### Fade 애니메이션

명언이 변경될 때 카드에 `fade-out`과 `fade-in` 클래스를 순서대로 적용합니다.
이를 통해 새로운 명언이 자연스럽게 나타납니다.

### 라이트 테마와 다크 테마

- `라이트` 버튼을 클릭하면 밝은 테마로 변경됩니다.
- `다크` 버튼을 클릭하면 어두운 테마로 변경됩니다.
- CSS 변수를 사용해 테마별 색상을 관리합니다.
- 선택한 테마는 `localStorage`에 저장되므로 새로고침 후에도 유지됩니다.

### 명언 복사

복사 버튼을 클릭하면 명언과 작가를 클립보드에 복사합니다.
복사에 성공하거나 실패하면 화면 아래쪽에 알림 메시지가 표시됩니다.

### 반응형 디자인

화면 크기에 따라 명언 카드와 버튼 크기가 조정됩니다.
데스크톱과 모바일 화면 모두에서 사용할 수 있습니다.

## HTML, CSS, JavaScript의 역할

### HTML: 구조

`index.html`은 화면에 무엇을 배치할지 정의합니다.

- 명언 제목과 안내 문구
- 명언, 작가, 카테고리 영역
- 새로운 명언 버튼
- 복사 버튼
- 라이트/다크 테마 버튼

### CSS: 디자인

`style.css`는 화면이 어떻게 보일지 정의합니다.

- 색상과 글꼴
- 명언 카드의 크기와 배치
- 버튼 스타일
- 라이트/다크 테마 색상
- Fade 애니메이션
- 모바일 반응형 레이아웃

### JavaScript: 동작

`script.js`는 사용자의 동작에 따라 화면을 변경합니다.

- 버튼 클릭 이벤트 처리
- 무작위 명언 선택
- HTML 요소의 텍스트 변경
- 클립보드 복사
- 테마 변경과 저장

## 동작 흐름

```text
사용자가 버튼 클릭
        ↓
JavaScript 이벤트 함수 실행
        ↓
새 명언 또는 테마 선택
        ↓
HTML 요소의 내용과 CSS 클래스 변경
        ↓
화면에 새로운 상태 표시
```

## 사용한 기술

- HTML5
- CSS3
- JavaScript
- Web Clipboard API
- Web Storage API (`localStorage`)
- Google Fonts

## 참고 사항

클립보드 복사 기능은 브라우저의 보안 정책에 따라 `localhost` 또는 HTTPS 환경에서 더 안정적으로 동작합니다.
일반적인 최신 브라우저에서는 파일을 직접 열어도 대부분 정상적으로 사용할 수 있습니다.
